# dynamics365/

Bounded context for **Dynamics 365 Customer Service** patterns.

**Status: placeholder — not implemented.** This directory currently contains no
solution exports, connector code, credentials, or configuration referencing any
real Dynamics 365 tenant, because none exists for this project.

**Intended scope (future milestone):** reference case-management design
artefacts (entity/table model for the [`business_process`](../business_process/)
taxonomy and lifecycle, example Power Automate touch-points, illustrative
configuration) that demonstrate how the platform-neutral business process could
be realised on Dynamics 365 — as one interchangeable implementation among
several, not the source of truth for the process itself. See
[`docs/architecture.md`](../docs/architecture.md) (bounded-context principle)
and [`docs/roadmap.md`](../docs/roadmap.md).
