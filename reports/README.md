# reports/

Destination for generated reports (e.g. future [`analytics/`](../analytics/)
output) — evidence artefacts intended to be reproducible from code in this
repository, not hand-authored.

Contents of this directory are **git-ignored** (except this README and
`.gitkeep`) — treat anything here as reproducible, disposable output.
`case_summary.json`, a small case-count summary generated by
[`business_process/evidence.py`](../business_process/evidence.py), lands here
when the generator is run (`python -m business_process.evidence`); it is not
committed by default. Nothing in this directory should ever be presented as
evidence of a live/production system; see the
[Portfolio & Simulation Disclaimer](../README.md#10-portfolio--simulation-disclaimer).
