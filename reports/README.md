# reports/

Destination for generated reports (e.g. future [`analytics/`](../analytics/)
output) — evidence artefacts intended to be reproducible from code in this
repository, not hand-authored.

**Tracking policy:** contents of this directory are **git-ignored by
default** (`reports/*`), with narrow, deliberate exceptions:

| File | Tracked? | Why |
|------|----------|-----|
| `README.md`, `.gitkeep` | Yes | Keep the directory and its intent documented, even when empty. |
| `case_summary.json` | **Yes** (explicit `.gitignore` exception) | Small, deterministic portfolio evidence generated by [`business_process/evidence.py`](../business_process/evidence.py) — worth reviewing without having to regenerate it. |
| `automation_summary.json` | **Yes** (explicit `.gitignore` exception) | Small, deterministic Power Platform automation evidence generated by [`power_platform/evidence.py`](../power_platform/evidence.py) — flow/step/connector/approval counts. Simulated evidence only; see its `note` field. |
| `agentic_ai_evaluation_summary.json` | **Yes** (explicit `.gitignore` exception) | Small, deterministic Milestone 5 evaluation summary generated by [`ai/evaluation.py`](../ai/evaluation.py). Synthetic/reference evidence only; see its `note` field. |
| Anything else | No | Transient/regenerable output. Re-running a generator (e.g. `python -m business_process.evidence`, `python -m power_platform.evidence`, `python -m ai.evaluation`) should never be a reason to touch source control. |

If a future milestone adds another generator whose output is genuinely worth
committing (not just reproducible-on-demand), add its filename as its own
narrow `!reports/<file>` exception in [`.gitignore`](../.gitignore) — do not
broadly unignore this directory.

Nothing in this directory should ever be presented as evidence of a
live/production system; see the
[Portfolio & Simulation Disclaimer](../README.md#10-portfolio--simulation-disclaimer).
