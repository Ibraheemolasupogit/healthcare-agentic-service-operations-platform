# outputs/

Destination for generated, run-specific artefacts (e.g. ad-hoc exports
produced while working in this repository).

Contents of this directory are **git-ignored** (except this README and
`.gitkeep`) — nothing here is meant to be committed or treated as a durable
project artefact. Durable, reviewed reports belong in [`reports/`](../reports/)
once generated by a script under version control.
