# power_platform/

Bounded context for **Power Platform** (Power Apps, Power Automate, Dataverse)
patterns.

**Status: placeholder — not implemented.** This directory currently contains no
flow definitions, canvas/model-driven app exports, or Dataverse schema, because
none has been built yet.

**Intended scope (future milestone):** deterministic workflow patterns —
Power Automate flow designs and Dataverse table modelling — implementing the
routing, notification, and escalation steps of the case lifecycle defined in
[`business_process/`](../business_process/). Kept explicitly distinct from the
agentic AI in [`ai/`](../ai/) and [`copilot/`](../copilot/): this domain is
**deterministic automation**, not autonomous agent behaviour (see
[`docs/architecture.md`](../docs/architecture.md)).
