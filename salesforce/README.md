# salesforce/

Bounded context for **Salesforce Service Cloud** patterns.

**Status: placeholder — not implemented.** This directory currently contains no
Apex, metadata, connector code, credentials, or configuration referencing any
real Salesforce org, because none exists for this project.

**Intended scope (future milestone):** reference case-management design
artefacts (object model for the [`business_process`](../business_process/)
taxonomy and lifecycle, illustrative flow/automation touch-points) that
demonstrate how the platform-neutral business process could be realised on
Salesforce Service Cloud — as one interchangeable implementation among
several, not the source of truth for the process itself. See
[`docs/architecture.md`](../docs/architecture.md) (bounded-context principle)
and [`docs/roadmap.md`](../docs/roadmap.md).
