# analytics/powerbi/

Reference Power BI report specification for Milestone 6. No `.pbix`,
screenshots, deployed report, workspace, or production dataset exists.

## Report Pages

### Executive Service Overview

- Total cases
- Open cases
- SLA compliance
- Escalation rate
- Mean/median resolution time
- Service-category distribution

### Operational Queue Performance

- Workload by queue
- Open cases by queue
- Priority distribution
- SLA risk by queue/category

### SLA and Escalation

- SLA compliance rate
- Response and resolution breach counts
- Escalations
- Category/priority breakdown

### Automation Performance

- Workflow executions
- Simulated successful/failed executions
- Approval involvement
- Automation coverage over synthetic evidence

### Agentic AI Assurance

- Agent/tool invocations
- Read/recommendation/state-changing/consequential tool mix
- Approval-required actions
- AI evaluation pass/fail
- Refusal/safety outcomes

### Integration Reliability

- Integration deliveries
- Delivery success/failure/dead-letter status
- Duplicate webhook suppression
- Retry involvement
- Manual-review outcomes
- Source/target system distribution

All visuals should carry a synthetic/reference evidence label. The report
must not claim production performance, improvement percentages, or live
operational monitoring.
