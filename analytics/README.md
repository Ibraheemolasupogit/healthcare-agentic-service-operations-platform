# analytics/

Bounded context for **Microsoft Fabric / Power BI** analytics patterns.

**Status: placeholder — not implemented.** This directory currently contains no
Fabric items, Power BI reports, or dataset connections, because none has been
built yet.

**Intended scope (future milestone):** operational reporting over synthetic
case data produced by [`business_process/`](../business_process/) and
[`data/`](../data/) — e.g. case volumes by [`ServiceCategory`], lifecycle
stage dwell time — designed to be portable evidence (exportable, not locked to
one BI tool) rather than a single dashboard artefact. See
[`docs/architecture.md`](../docs/architecture.md).
