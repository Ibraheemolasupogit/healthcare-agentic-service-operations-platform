# data/

Home for **synthetic data only**.

**Status: populated with deterministic, generated evidence.**
`data/synthetic/` now holds JSON artefacts generated by
[`business_process/evidence.py`](../business_process/evidence.py) (run via
`python -m business_process.evidence`):

- `service_taxonomy.json` — service categories, case lifecycle, and priorities
- `routing_config.json` — category → queue routing rules and queue owners
- `sla_config.json` — the full SLA target matrix (category × priority)
- `cases.json` — the six deterministic synthetic case fixtures (with full
  audit history), one per service category

Every file is regenerated identically by re-running the generator — nothing
here is hand-authored, and none of it is fetched from a live system.

**Rules for anything added here (see [`docs/governance.md`](../docs/governance.md)):**

- Synthetic/fabricated data only — never real patient, clinical, staff, or
  organisational data.
- No data that could be mistaken for a real NHS or healthcare provider export.
- Every dataset must be traceable to a generator/script in this repository, not
  hand-authored to imply a real source system.
