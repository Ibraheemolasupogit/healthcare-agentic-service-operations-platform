# copilot/copilot_studio/

Reference Copilot Studio architecture for Milestone 5. This directory holds
structured topic specifications and generated JSON snapshots only. It does
not contain exported Copilot Studio solutions, deployed topic packages,
screenshots, tenant IDs, or production telemetry.

## Architecture

```text
Conversational topic
    -> bounded agent orchestration
    -> allow-listed tool
    -> canonical service operation or synthetic knowledge
    -> audit evidence
```

Topics may interpret a user's intent, collect fields, retrieve operational
knowledge, summarize, or recommend triage. They do not decide lifecycle
validity, routing, SLA status, escalation, approval, or canonical case state.

`topics.py` is the source for `topics.json`, regenerated by:

```text
python -m ai.evaluation
```
