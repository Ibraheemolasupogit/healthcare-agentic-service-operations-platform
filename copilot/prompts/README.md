# copilot/prompts/

Versioned prompt/template metadata for Milestone 5. Prompts define purpose,
input schema, output schema, and safety constraints for triage,
summarisation, knowledge answering, tool selection, and escalation
explanation.

Prompts are not hidden business-rule containers: lifecycle transitions,
routing, SLA evaluation, escalation, and approval remain deterministic and
outside prompt text.

`prompt_templates.json` is regenerated by:

```text
python -m ai.evaluation
```
